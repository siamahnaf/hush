# Changelog

## 1.0.3

- Link a renamed or moved folder to its old backups, then pull everything from This Workspace.
- Delete a whole project's backups from Other Projects in Drive.
- Unlink a folder from linked backups.

## 1.0.2

- Delete backups you no longer need, one at a time or several at once.
- Icons for the Hush sidebar views.

## 1.0.1

- Smaller font in the Raw view.
- Long lines now wrap in the Raw view.

## 1.0.0
- Change color and fixed font size issues

## 0.1.0

- First release.
- Encrypted backup of `.env` files to your own Google Drive.
- Automatic upload on save, manual pull, push all and pull all.
- Conflict detection with a side-by-side compare.
- Version history with restore.
- Change passphrase, rotate vault key, lock, disconnect and delete vault.
